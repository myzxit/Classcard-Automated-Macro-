# 아이폰 버전

안드로이드 앱 / 크롬 확장과 **같은 엔진**(`extension/engine/**`)을 아이폰 사파리에서 돌립니다.
`ios/build.mjs` 가 그 엔진을 한 파일로 묶고, 아이폰용 조작 화면을 붙입니다.

## 먼저 알아야 할 것 — 아이폰에서 안 되는 모드가 있습니다

클래스카드의 일부 화면은 **진짜 사람이 누른 입력인지**(`event.isTrusted`) 확인하고,
아니면 그 입력을 그냥 버립니다. 안드로이드 앱은 WebView 에 네이티브 `MotionEvent`·`KeyEvent` 를
꽂아 넣고, 크롬 확장은 `chrome.debugger`(CDP)로 같은 일을 해서 이 검사를 통과합니다.

**iOS 사파리에는 웹 내용에 진짜 터치·키를 꽂아 넣는 공개 방법이 없습니다.**
사파리 웹 확장에도 `chrome.debugger` 가 없습니다. 그래서 아래 모드는 아이폰에서
**어떤 방법으로도** 동작하지 않습니다. 우리 코드의 한계가 아니라 iOS 의 제약입니다.

| 모드 | 아이폰 | 이유 |
|---|---|---|
| 📐 문법 | ✅ | 정답을 화면에서 읽어 값으로 넣고 누릅니다 |
| 🎴 단어 매칭 | ✅ | 사이트가 `isTrusted` 를 보지 않습니다 |
| 🃏 단어 테스트 | ✅ | 단어장이 있으면 동작 (먼저 [단어장 가져오기]) |
| 🗂 암기 | ⚠️ | SPACE 를 합성 키로 보냅니다. 화면에 따라 안 먹을 수 있습니다 |
| ⤵ 단어장 가져오기 | ✅ | 화면에 그려진 카드에서 읽습니다 |
| 🔁 리콜 | ❌ | 정답 클릭이 `isTrusted` 검사를 통과해야 합니다 |
| ⌨ 스펠 | ❌ | 입력창의 마지막 keydown 이 진짜여야 채점됩니다 |
| 📖 문장 암기 · 📝 문장 리콜 · 📕 문장 테스트 · ✳ 스크램블 | ❌ | 낱말 버튼이 합성 클릭을 무시합니다 |

안 되는 모드는 화면에서 회색으로 잠겨 있어 잘못 눌러도 아무 일도 일어나지 않습니다.
**리콜·스펠·문장 계열까지 쓰려면 안드로이드 앱이나 PC 크롬 확장을 쓰세요.**

## 방법 1 — 북마클릿 (맥 없이 바로 됨, 권장)

아이폰만 있으면 됩니다. 설치도, 개발자 계정도 필요 없습니다.

1. 사파리에서 아무 페이지나 북마크에 추가합니다 (공유 → 북마크 추가).
2. 북마크 → 편집 → 방금 만든 북마크를 누릅니다.
3. **이름**을 `클래스카드`, **주소**를 `ios/dist/bookmarklet.txt` 의 내용으로 통째로 바꿉니다.
   (680바이트짜리 한 줄입니다. GitHub 에서 파일을 열어 복사하세요.)
4. classcard.net 에서 학습 화면을 연 다음, 주소창에 `클래스카드` 를 치고 그 북마크를 누릅니다.
5. 화면 아래에 조작판이 뜹니다. 모드를 누르면 실행됩니다.

북마크는 저장소의 `ios/dist/classcard-ios.js` 를 그때그때 받아옵니다.
그래서 **저장소가 업데이트되면 자동으로 최신 버전**이 됩니다.

> 인터넷 없이 쓰고 싶으면 `ios/dist/inline-snippet.js` 를 통째로 쓰면 되지만,
> 200KB 가 넘어 북마크 주소에는 넣을 수 없습니다 (단축어 앱 등에서 실행하세요).

## 방법 2 — 사파리 웹 확장 앱 (맥 필요)

크롬 확장과 같은 코드를 아이폰 앱으로 감싸서, 사파리 확장으로 항상 켜 둘 수 있습니다.
**맥과 Xcode 가 있어야 만들 수 있습니다.** (아이폰 앱 빌드·서명은 맥에서만 됩니다.)

```bash
bash ios/safari/convert.sh
```

애플의 공식 변환기(`xcrun safari-web-extension-converter`)로 Xcode 프로젝트를 만듭니다.
변환 전에 `debugger` 권한을 자동으로 빼냅니다 — 사파리에는 없는 권한이라 그대로 두면 경고가 납니다.

Xcode 가 열리면 **Signing & Capabilities** 에서 본인 Apple ID 팀을 고르고 아이폰에 설치합니다.
무료 Apple ID 로도 되지만 **7일마다 다시 설치**해야 합니다(애플 정책).
설치 후 `설정 → Safari → 확장 프로그램` 에서 켜세요.

이 방법도 위의 ❌ 모드는 여전히 동작하지 않습니다. 같은 iOS 제약을 받습니다.

## 다시 빌드하기

엔진(`extension/engine/**`)을 고쳤으면 다시 묶어야 아이폰에 반영됩니다.

```bash
node ios/build.mjs
```

- `ios/dist/classcard-ios.js` — 사파리에서 실행되는 한 파일
- `ios/dist/bookmarklet.txt` — 북마크에 넣을 한 줄 (위 파일을 받아오기만 합니다)
- `ios/dist/inline-snippet.js` — 통짜 버전

`ios/src/shim.js` 만 아이폰 전용 코드입니다(페이지 안에서 도는 드라이버 + 조작판).
나머지는 안드로이드·크롬과 **같은 엔진 그대로** 입니다. 엔진을 고치면 세 곳이 함께 고쳐집니다.
